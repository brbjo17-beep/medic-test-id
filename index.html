Tentang Medic Test ID

Kenapa website ini dibuat?

Medic Test ID berawal dari kebutuhan sederhana: belajar kedokteran itu sudah cukup berat tanpa harus menghabiskan waktu mencari soal yang sesuai, menerjemahkan materi, atau bingung harus mulai dari mana.

Website ini dibuat sebagai tempat latihan yang sederhana, nyaman, dan mudah diakses mahasiswa kedokteran Indonesia. Fokusnya bukan sekadar mendapat skor tinggi, tetapi memahami kenapa suatu jawaban benar dan kenapa kita salah.

Semua bank soal akan terus dikembangkan agar Medic Test ID dapat digunakan dalam jangka panjang sebagai teman belajar, terutama ketika kepala sudah penuh dan kamu cuma butuh satu tempat untuk mulai latihan.

💙 Tidak harus pintar dulu untuk mulai latihan. Justru kita latihan karena belum tahu semuanya.
